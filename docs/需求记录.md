# ClipHarbor 需求记录

记录日期：2026-10-31。以下是待讨论的产品想法，不代表已经决定实施或确定方案。先记录，后续再确定优先级和范围。

## 本地体验优化

### 重复内容过滤

- 期望：重复复制的内容不要不断出现在剪贴板历史中。
- 已实现：新增和加载历史时过滤重复项。重新复制已有普通记录会移到普通列表最前；置顶记录位置不变。文本忽略换行编码与 Unicode 规范表示的差别；图片、文件和富文本按完整数据精确比较，置顶记录优先保留。
- 暂不合并格式、文件路径、图片编码或空格等有差异的内容，避免误删。

### 常用内容统计与排序

- 期望：统计经常粘贴的内容，让常用项更容易找到，例如排序靠前。
- 当前约定：点击粘贴不改变原列表顺序；重新复制已有普通记录移到普通列表最前，置顶项位于顶部。
- 已实现：独立「常用」视图按本机累计的粘贴指令次数排序，置顶优先；相同次数保留原列表相对顺序。仅在 ClipHarbor 发出粘贴指令后计数，不统计手动粘贴，也无法确认目标应用是否接受粘贴。清空普通历史时删除其计数，置顶项及其计数保留。

### 2026-11-06 本地稳定性与使用体验

- 历史损坏时持续提示保存暂停，先备份原文件再恢复写入；历史目录和文件收紧为当前账号访问。
- 多张图片与支持的混合项目按顺序保存、恢复；HTML 内容支持文字展示和搜索。
- 中文输入法组字按键不触发历史操作；自动粘贴前核对剪贴板版本，连续选择只执行最后一次请求。
- 支持单条删除、清空确认、暂停记录、完整预览和纯文本粘贴。暂停偏好跨重启保存，恢复时不补录暂停期间内容。
- 历史改为后台串行保存并合并连续更新，退出前等待保存完成；当前仍采用普通历史 100 条限制，字节容量上限尚未设置。
- 微信关联冲突禁止同名回退；可信消息边界来自与当前文本对应的微信复制数据，纯文本歧义保留原文并提示。
- 微信搜索展示已扫描数量并支持取消，取消清理本次未完成结果。
- 验证覆盖合成剪贴板、文件权限、损坏恢复、保存顺序、输入法组字事件、粘贴竞争、微信冲突关联和取消清理；真实微信与跨应用粘贴仍需桌面验收。

## 云端服务与跨设备（暂不开发）

- 设想提供云端服务和用户身份登录，让用户在不同设备上使用自己的剪贴板历史。
- 跨设备同步可能作为未来收费功能，收费模式和免费范围尚未决定。
- 待讨论：支持的平台、同步的内容类型与文件处理、冲突处理、离线使用、账号与设备管理、隐私与安全、数据保留和删除，以及收费方案。

## 多平台版本（暂不开发）

- 长期计划：除 Mac 版外，未来还希望提供 Android、iOS 和 Windows 版本。
- 当前范围：只做 Mac 版；其他平台暂不设计或开发，实施顺序和功能范围以后再确定。
- 多平台版本未来可与跨设备同步设想一起讨论，但同步方案和收费模式尚未确定。
