# ClipHarbor

macOS 菜单栏剪贴板历史工具，记录文本、图片、文件引用以及剪贴板中可读取的富文本。启动后默认按 ⌥⇧V 打开历史，也可在面板右下角「设置 → 快捷键」中切换为 ⌃⌥V 或关闭。先在目标应用选好输入位置，再点击记录即可尝试粘贴；自动粘贴需要在系统设置「隐私与安全性 → 辅助功能」中允许 ClipHarbor，未授权时可手动粘贴。

每条记录右侧可置顶、查看完整预览，或在操作菜单中选择原格式粘贴、纯文本粘贴和删除。置顶项保存在列表顶部，不受普通历史 100 条的限制；「设置 → 清空未置顶」确认后删除普通记录及其计数，置顶项保留。点击粘贴不改变「全部」列表顺序；重新复制已有普通记录会移到普通列表最前，置顶项位置保持不变。「常用」视图按 ClipHarbor 发起的粘贴次数排序，置顶项优先；次数保存在本机。系统不反馈目标应用是否接受粘贴，因此次数表示已发送粘贴指令，不代表实际粘贴成功；手动粘贴不会计入。文本仅换行编码或 Unicode 规范表示不同时视为重复，其他类型按完整内容比较。

搜索框支持上下键选择、回车粘贴；中文输入法组字期间仍由输入法处理按键。如果等待粘贴时剪贴板已被其他内容更新，本次自动粘贴会取消，保留新的剪贴板内容。可在面板中暂停记录；暂停状态跨重启保留，恢复时不会补录暂停期间留在剪贴板中的内容。

重复复制置顶项、当前首个普通项或空白文本时，不刷新历史列表或重写历史文件。富文本的列表、搜索和预览复用本机内存中的文字缓存，记录删除或淘汰后清理对应缓存。

历史和置顶保存在本机 `~/Library/Application Support/ClipHarbor/history.plist`，目录和文件分别使用 `0700`、`0600` 权限。写入在后台串行进行，连续更新会合并，正常退出会等待最后的修改保存；失败时可以留在应用中重试。旧版文本与图片历史会自动读取。历史文件损坏时持续显示保存暂停，可点击「备份并恢复」，先在同目录保留 `history-damaged-*.plist`，再保存当前内存中的记录。恢复不会自动修复旧文件里的内容。数据未加密；标记为敏感或临时的剪贴板内容不会记录，但没有被来源应用标记为敏感的密码等仍可能被记录。

复制文件时保存的是文件位置，不是文件副本；文件移动、删除或所在磁盘不可用后，历史记录无法恢复文件。多图片和混合项目按顺序保存支持的表示。富文本尽量保存文字、HTML、RTF、RTFD 和图片表示；微信专有格式及来源应用未提供给系统的内容不保证能恢复。HTML 搜索与纯文本粘贴使用本地文字提取，不加载远端资源；少见命名实体可能保留原样。大图片和富文本会占用本地磁盘，目前没有按字节设置总容量上限。

需要 macOS 13 或更新版本，以及 Swift 开发工具。运行：

```sh
./run.sh
```

在菜单栏面板右下角「设置」中点击「登录时启动」可开启或关闭登录后自动启动；如系统要求，请在「系统设置 → 通用 → 登录项与扩展」中允许 ClipHarbor。请保持生成的 `.build/ClipHarbor.app` 路径不变，移动或删除应用后需要重新设置。

验证：

```sh
./test.sh
```

## 微信聊天转上下文

1. 在微信选中多条聊天记录并复制，打开 ClipHarbor，点击「微信聊天导出」。
2. 点击「自动转换并保存」。程序会重新读取当前剪贴板，并自动查找本机微信数据目录；也可以更换搜索目录。搜索会显示已扫描项目数，可以取消；取消后清理本次未完成的结果，已有导出不受影响。
3. 导出完成后点击「在访达中显示结果」。结果包含 `conversation.md` 和 `images` 文件夹，默认保存在 `~/Library/Application Support/ClipHarbor/微信聊天导出/`。
4. 查看 Markdown 的图片关联报告，再把文字内容和对应图片附件提供给 ChatGPT。工具不会自动上传或发送任何内容。

关闭导出窗口会取消当前任务；正常退出应用时会等待取消和清理完成，再保存历史并退出。清理失败会显示未完成目录的路径，可以留在应用中检查或明确选择仍然退出。

程序优先根据与当前文本对应的微信多选复制数据，建立同一条消息的文字与本机图片关联；无法获取该关联时，才会尝试唯一同名且可解码的图片，不会凭时间猜测。已知冲突或不对应的关联不会继续回退同名匹配。找不到、存在冲突、搜索不完整或无法解码的图片都会保留原引用并列入未匹配报告。不同微信版本和加密文件未必提供可恢复的图片；同名匹配也建议人工核对。消息边界优先使用对应的微信复制数据；仅有纯文本且边界有歧义时保留原文并提示，识别条数可能仅供参考。导出目录权限为仅当前用户可访问，文件包含私人聊天内容。
