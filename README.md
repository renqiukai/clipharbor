# ClipHarbor

macOS 菜单栏剪贴板历史工具，记录文本、图片、文件引用以及剪贴板中可读取的富文本。启动后默认按 ⌥⇧V 打开历史，也可在面板的「快捷键」中切换为 ⌃⌥V 或关闭。先在目标应用选好输入位置，再点击记录即可尝试粘贴；自动粘贴需要在系统设置「隐私与安全性 → 辅助功能」中允许 ClipHarbor，未授权时可手动粘贴。

每条记录右侧可置顶。置顶项保存在列表顶部，不受普通历史 100 条的限制；「清空未置顶」不会清除置顶项。点击记录及重新复制相同内容不会改变「全部」列表顺序。「常用」视图按 ClipHarbor 发起的粘贴次数排序，置顶项优先；次数保存在本机。系统不反馈目标应用是否接受粘贴，因此次数表示已发送粘贴指令，不代表实际粘贴成功；手动粘贴不会计入。文本仅换行编码或 Unicode 规范表示不同时视为重复，其他类型按完整内容比较。

历史和置顶保存在本机 `~/Library/Application Support/ClipHarbor/history.plist`，退出后不会继续记录。旧版文本与图片历史会自动读取。数据未加密；标记为敏感或临时的剪贴板内容不会记录，但没有被来源应用标记为敏感的密码等仍可能被记录。

复制文件时保存的是文件位置，不是文件副本；文件移动、删除或所在磁盘不可用后，历史记录无法恢复文件。富文本尽量保存文字、HTML、RTF、RTFD 和图片表示；微信专有格式及来源应用未提供给系统的内容不保证能恢复。大图片和富文本会占用本地磁盘。

需要 macOS 13 或更新版本，以及 Swift 开发工具。运行：

```sh
./run.sh
```

在菜单栏面板中点击「登录时启动」可开启或关闭登录后自动启动；如系统要求，请在「系统设置 → 通用 → 登录项与扩展」中允许 ClipHarbor。请保持生成的 `.build/ClipHarbor.app` 路径不变，移动或删除应用后需要重新设置。

验证：

```sh
./test.sh
```

## 微信聊天转上下文

1. 在微信选中多条聊天记录并复制，打开 ClipHarbor，点击「微信聊天转上下文」。
2. 点击「自动转换并保存」。程序会重新读取当前剪贴板，并自动查找本机微信数据目录；也可以更换搜索目录。
3. 导出完成后点击「在访达中显示结果」。结果包含 `conversation.md` 和 `images` 文件夹，默认保存在 `~/Library/Application Support/ClipHarbor/微信聊天导出/`。
4. 查看 Markdown 的图片关联报告，再把文字内容和对应图片附件提供给 ChatGPT。工具不会自动上传或发送任何内容。

程序优先根据微信多选复制数据中同一条消息的文字与本机图片路径建立关联；无法获取该关联时，才会尝试唯一同名且可解码的图片，不会凭时间猜测。找不到、存在冲突、搜索不完整或无法解码的图片都会保留原引用并列入未匹配报告。不同微信版本和加密文件未必提供可恢复的图片；同名匹配也建议人工核对。聊天头无法识别时会原样导出文本。导出目录权限为仅当前用户可访问，文件包含私人聊天内容。
